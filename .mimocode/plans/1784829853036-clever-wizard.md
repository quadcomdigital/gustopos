# Piano: Storico e Riepilogo Preparazioni

## Obiettivo

Aggiungere visibilità sulle preparazioni effettuate nella tab Prep, mostrando:
1. Storico dettagliato delle preparazioni
2. Riepilogo aggregato per ingrediente/periodo
3. Label corrette nei movimenti di magazzino

## Stato attuale

- Le preparazioni vengono salvate in `stock_movements` con `movementType: "preparation"`
- Le conversioni definite in Prep sono usate automaticamente dalle BOM
- Manca UI per visualizzare lo storico
- Mancano label in `StockMovementsDrawer.tsx`

Aggiungere metodo `listPreparationHistory`:

```typescript
async listPreparationHistory(filters?: {
  ingredientId?: string;
  staffId?: string;
  from?: Date;
  to?: Date;
  limit?: number;
  offset?: number;
}): Promise<{ items: StockMovement[]; total: number }> {
  const tenantId = getTenantIdOrDefault();
  const conditions = [
    eq(stockMovements.tenantId, tenantId),
    inArray(stockMovements.movementType, ['preparation', 'bom_preparation'])
  ];
  
  if (filters?.ingredientId) {
    conditions.push(eq(stockMovements.ingredientId, filters.ingredientId));
  }
  if (filters?.staffId) {
    conditions.push(eq(stockMovements.staffId, filters.staffId));
  }
  if (filters?.from) {
    conditions.push(gte(stockMovements.createdAt, filters.from));
  }
  if (filters?.to) {
    conditions.push(lte(stockMovements.createdAt, filters.to));
  }
  
  const limit = filters?.limit ?? 50;
  const offset = filters?.offset ?? 0;
  
  const [items, countResult] = await Promise.all([
    db.select()
      .from(stockMovements)
      .where(and(...conditions))
      .orderBy(desc(stockMovements.createdAt))
      .limit(limit)
      .offset(offset),
    db.select({ count: sql<number>`count(*)::int` })
      .from(stockMovements)
      .where(and(...conditions))
  ]);
  
  return {
    items: items.map(m => ({
      id: m.id,
      ingredientId: m.ingredientId,
      movementType: m.movementType,
      quantity: Math.abs(Number(m.quantity)),
      unit: '', // da recuperare dall'ingrediente
      notes: m.notes,
      staffId: m.staffId,
      createdAt: m.createdAt.toISOString()
    })),
    total: countResult[0]?.count ?? 0
  };
}
```

### 2. Frontend - API Client

**File:** `apps/web/src/shared/api/client.ts`

Aggiungere funzione:

```typescript
export async function fetchPreparationHistory(filters?: {
  ingredientId?: string;
  staffId?: string;
  from?: string;
  to?: string;
  limit?: number;
  offset?: number;
}): Promise<{
  items: Array<{
    id: string;
    ingredientId: string;
    movementType: string;
    quantity: number;
    unit: string;
    notes: string;
    staffId: string | null;
    createdAt: string;
  }>;
  total: number;
}> {
  const params = new URLSearchParams();
  if (filters?.ingredientId) params.append('ingredientId', filters.ingredientId);
  if (filters?.staffId) params.append('staffId', filters.staffId);
  if (filters?.from) params.append('from', filters.from);
  if (filters?.to) params.append('to', filters.to);
  if (filters?.limit) params.append('limit', String(filters.limit));
  if (filters?.offset) params.append('offset', String(filters.offset));
  
  const response = await authorizedFetch(
    `${API_URL}/api/preparations/history?${params.toString()}`
  );
  return response.json();
}
```

### 3. Frontend - Componente Storico Preparazioni

**File:** `apps/web/src/components/inventory/PreparationHistory.tsx` (NUOVO)

Creare componente che mostra:
- Lista preparazioni con filtri (ingrediente, data, operatore)
- Riepilogo aggregato per ingrediente
- Totali per periodo

```typescript
interface PreparationHistoryProps {
  inventory: Ingredient[];
}

export default function PreparationHistory({ inventory }: PreparationHistoryProps) {
  const [history, setHistory] = useState<PreparationHistoryItem[]>([]);
  const [filters, setFilters] = useState({
    ingredientId: '',
    from: '',
    to: ''
  });
  const [loading, setLoading] = useState(false);
  
  // Carica storico
  const loadHistory = async () => {
    setLoading(true);
    try {
      const result = await fetchPreparationHistory(filters);
      setHistory(result.items);
    } catch (err) {
      console.error('Errore caricamento storico:', err);
    } finally {
      setLoading(false);
    }
  };
  
  useEffect(() => {
    loadHistory();
  }, [filters]);
  
  // Raggruppa per ingrediente
  const summary = useMemo(() => {
    const map = new Map<string, { ingredient: Ingredient; totalQty: number; count: number }>();
    for (const item of history) {
      const ing = inventory.find(i => i.id === item.ingredientId);
      if (!ing) continue;
      const existing = map.get(item.ingredientId) ?? { ingredient: ing, totalQty: 0, count: 0 };
      existing.totalQty += item.quantity;
      existing.count += 1;
      map.set(item.ingredientId, existing);
    }
    return Array.from(map.values());
  }, [history, inventory]);
  
  return (
    <div className="space-y-4">
      {/* Filtri */}
      <div className="grid grid-cols-3 gap-2">
        <select
          value={filters.ingredientId}
          onChange={(e) => setFilters({ ...filters, ingredientId: e.target.value })}
          className="px-3 py-2 border border-border rounded"
        >
          <option value="">Tutti gli ingredienti</option>
          {inventory.map(ing => (
            <option key={ing.id} value={ing.id}>{ing.name}</option>
          ))}
        </select>
        <input
          type="date"
          value={filters.from}
          onChange={(e) => setFilters({ ...filters, from: e.target.value })}
          className="px-3 py-2 border border-border rounded"
        />
        <input
          type="date"
          value={filters.to}
          onChange={(e) => setFilters({ ...filters, to: e.target.value })}
          className="px-3 py-2 border border-border rounded"
        />
      </div>
      
      {/* Riepilogo */}
      {summary.length > 0 && (
        <div className="bg-blue-50 border border-blue-200 rounded-lg p-3">
          <h4 className="text-sm font-bold mb-2">Riepilogo periodo</h4>
          <div className="space-y-1">
            {summary.map(s => (
              <div key={s.ingredient.id} className="flex justify-between text-sm">
                <span>{s.ingredient.name}</span>
                <span className="font-bold">
                  {s.totalQty.toFixed(3)} {s.ingredient.unit} ({s.count} preparazioni)
                </span>
              </div>
            ))}
          </div>
        </div>
      )}
      
      {/* Lista dettagliata */}
      <div className="space-y-2">
        {history.map(item => {
          const ing = inventory.find(i => i.id === item.ingredientId);
          return (
            <div key={item.id} className="bg-white border border-border rounded-lg p-3">
              <div className="flex justify-between items-start">
                <div>
                  <p className="font-medium">{ing?.name ?? 'Ingrediente sconosciuto'}</p>
                  <p className="text-xs text-text-muted">{item.notes}</p>
                  {item.staffId && (
                    <p className="text-xs text-text-muted">Operatore: {item.staffId}</p>
                  )}
                </div>
                <div className="text-right">
                  <p className="font-bold text-purple-600">
                    {item.quantity.toFixed(3)} {ing?.unit}
                  </p>
                  <p className="text-xs text-text-muted">
                    {new Date(item.createdAt).toLocaleString('it-IT')}
                  </p>
                </div>
              </div>
            </div>
          );
        })}
      </div>
    </div>
  );
}
```
