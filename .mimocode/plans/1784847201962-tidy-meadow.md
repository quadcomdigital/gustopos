# Plan: Fix Low-Stock Alert Duplication

## Problem

There are **two separate low-stock alert systems** that both show "X sotto soglia" with amber styling:

1. **`InventoryTabs.tsx`** — renders `LowStockAlert` component (expandable banner with reorder suggestions, supplier info, estimated cost, "Crea Ordine Acquisto" button) in the summary cards area. Always visible above the tabs.

2. **`IngredientsTab.tsx`** — has its own inline amber filter toggle ("X sotto soglia, Clicca per filtrare") inside the tab content. Clicking it filters the ingredient list to show only low-stock items.

The low-stock count is calculated independently in both files:
- `InventoryTabs.tsx:184` — `inventory.filter((i) => i.quantity <= i.minThreshold && i.isActive).length`
- `IngredientsTab.tsx:130` — `inventory.filter((i) => i.quantity <= i.minThreshold).length`

Note: `IngredientsTab` doesn't filter by `isActive`, which is a subtle inconsistency.

## Proposed Fix

**Merge the two into one unified system.** Keep the `LowStockAlert` component (it has richer functionality — reorder suggestions, cost estimates, purchase order button) and integrate the filter toggle into it. Remove the duplicate from `IngredientsTab`.

### Changes

1. **`LowStockAlert.tsx`** — add an `onToggleFilter` / `isFiltered` prop so it can also act as a filter trigger
2. **`InventoryTabs.tsx`** — pass filter state down to `LowStockAlert`
3. **`IngredientsTab.tsx`** — remove the inline amber filter toggle (lines 399-421), keep the `filterLowStock` state but control it from the parent via a new prop
4. **Fix the `isActive` inconsistency** — `IngredientsTab` should also filter by `isActive` like `InventoryTabs` does

### Alternative (simpler)

Just remove the `IngredientsTab` inline toggle entirely and let `LowStockAlert` be the single source. The filter functionality can be added to `LowStockAlert` as an optional callback.

## Files to Modify
